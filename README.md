The Mental Health Analytics Dashboard is an interactive data analysis project designed to explore how various factors such as stress, sleep, anxiety, age, and productivity influence mental well-being. The project applies Exploratory Data Analysis (EDA) techniques to uncover patterns and relationships within a structured dataset.
Using Python-based visualization tools and Streamlit, the system transforms raw mental health data into meaningful insights through charts, metrics, and interactive filters. The dashboard enables users to dynamically explore data by gender and age group, making the analysis intuitive and easy to understand.
